# Modern Responsive Login Page

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![Responsive](https://img.shields.io/badge/Responsive-Yes-success?style=for-the-badge)

Uma interface de login moderna e responsiva desenvolvida com **HTML5** e **CSS3**, com foco na criação de layouts responsivos utilizando **Flexbox**, formulários e boas práticas de organização de código.

---

## 🎯 Objetivo

Este projeto foi desenvolvido para praticar conceitos fundamentais de desenvolvimento Front-end, incluindo:

- Estruturação de formulários em HTML
- Estilização com CSS
- Layout utilizando Flexbox
- Posicionamento de elementos
- Responsividade para diferentes tamanhos de tela
- Organização de arquivos em projetos Front-end
